# AI Galaxy 2026 — каталог нейросетей

**AI Galaxy 2026** — это интерактивный веб-каталог, который собирает информацию о более чем 50 современных нейросетях и ИИ-инструментах со всего мира. Проект представляет собой удобную карточную сетку с фильтрацией по категориям и поиском, а также содержит ссылки на крупнейшие агрегаторы ИИ (более 1000 инструментов).

## Описание

Каталог включает модели различных типов:
- Чат-боты и большие языковые модели (ChatGPT, Gemini, DeepSeek, YandexGPT и др.)
- Генераторы изображений (Midjourney, DALL-E 3, Stable Diffusion, Fusion Brain)
- Видео и анимация (Sora, Veo, Runway)
- Аудио и голос (ElevenLabs, Suno)
- Специализированные решения (Khanmigo, Consensus, Notion AI)

Все карточки содержат название, страну происхождения, краткое описание, теги и ссылку на официальный сайт.

## Особенности

- **Динамическая фильтрация** по категориям (чат, изображения, видео, аудио, специализированные, российские модели)
- **Поиск в реальном времени** по названию, стране, описанию и тегам
- **Адаптивный дизайн** — корректное отображение на мобильных устройствах
- **Статистика** (количество моделей, страны, год обновления)
- **Блок агрегаторов** с ссылками на крупнейшие каталоги ИИ (AIXploria, There's An AI For That, Futurepedia, RankmyAI)
- **Современный интерфейс** с градиентами, иконками Font Awesome и плавными анимациями

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, кастомные стили)
- JavaScript (ES6) — рендеринг карточек, фильтрация
- Google Fonts (Inter)
- Font Awesome 6 (иконки)
